# Two Halves

A calm co-op puzzle game for autistic players aged 10 to 14.
One player (the Explorer) sees the locked gate. The other (the Guide) holds the Guidebook with the rules. Talk it out together.

Designed by Panupan Donngen, Digital Media Engineering, Khon Kaen University.

## How to run

1. Open `index.html` in any modern browser (Chrome, Edge, Safari, Firefox). No install or server needed.
2. To share, send the whole folder (or the zip). Everything is in one file.

Works offline. With internet, it loads the Fredoka and Atkinson Hyperlegible fonts; without it, the browser uses a similar built-in font.

## How to play

- **Two devices (recommended):** open `index.html` on both. One person taps **Play as Explorer**, the other taps **Open the Guidebook**.
- **One device:** the Explorer uses the device and the Guide uses a printed Guidebook.
- Sit facing each other. The Guide must not see the Explorer's screen.
- There are 8 gates: Vine Garden, Symbol Town, then Maze Forest and a final gate with three locks.
- Vines can have buds (small round knobs). Count them: some rules depend on them.
- Swap roles after every gate.
- There is no timer and no game over. A wrong action only resets the lock.

## Settings

Soft sounds, calm motion, color letters on vines (for color vision differences), and light or dark theme. Progress is saved in the browser on that device only. Nothing is sent anywhere.
